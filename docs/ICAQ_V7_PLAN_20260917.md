# ICAQ V7：CLS引导的图像条件稀疏属性Query

日期：2026-09-17。独立代码目录`icaq_troika`；不修改Troika、CAMS及既有实验目录。
所有选择先在validation完成，双seed正式门槛通过前禁止读取test。

## 1. 动机

DAPQ的第y个属性文本Query天然携带标签身份，错配图像后仍有79.00% macro，不能证明patch
属性识别。ICAQ必须让Query只由图像产生，同时保留我们已验证有效的前景patch选择机制。

## 2. 结构

1. 保留冻结Troika的composition、attribute、object三个CLS分支；
2. 用冻结Troika的归一化attribute CLS特征生成唯一Query，不输入真实标签或属性文本Query；
3. Query在layer12 patch上形成语义key注意力，从layer6 patch value读取纹理、材质和局部形态；
4. 使用sparsemax，不手工指定patch个数，不加入foreground硬mask或中心ring；
5. 得到每张图唯一的局部属性视觉特征，与全部16个属性文本原型计算logits；
6. primitive attribute CLS保持不变；局部属性logits只通过零初始化gate加入composition候选分数。

这等价于：CLS先概括“这双鞋整体是什么”，再用该图像条件去patch中查询属性细节，最后由
全部属性原型竞争分类。由于只有一个图像Query，不存在按真实属性选择Query的标签捷径。

## 3. 训练

冻结完整Troika与CLIP，只训练ICAQ和composition gate，参数量预计约590万。

- composition CE：权重1.0；
- ICAQ属性标准CE与Balanced Softmax各0.5后合并：权重1.0；
- 不训练primitive attribute gate，不解冻视觉主干；
- 固定layer12 key、layer6 value、8头、学习率1e-4。

## 4. 验证顺序和门槛

### B0：工程检查

检查zero gate精确复现CLS、单Query输出形状、attention归一与稀疏性、属性损失反传到CLS
query投影和layer6/layer12投影、冻结参数无梯度。

### B0c：seed0一轮

进入错配审计的条件：局部属性macro明显高于随机初始化；预测覆盖至少12/16类；AUC相对CLS
下降不超过0.2点；primitive macro不变；attention不是全均匀或单patch塌缩。

### D34：图像错配审计

用固定偏移的其他验证图替换输入但保留原标签。要求错配图像局部macro不超过正常图像的50%，
且视觉特征余弦相似度明显低于DAPQ的0.9572。否则仍未真正使用图像证据，停止V7。

### D35：公共特征方向消歧审计（D34后追加）

D34实际出现“错配macro仅保留21.57%，但原始特征余弦仍为0.9619”的冲突。由于归一化CLIP
特征可能共享强公共均值方向，原始余弦未必反映分类所用的小角度变化。为避免直接修改门槛，
追加一次零训练审计：在完整validation特征上减去正常图像均值，再计算正常/错配特征余弦，
同时统计局部属性top-1一致率和概率L1变化。

只有以下三项同时满足才允许进入B1/B2：错配macro保留率不超过50%；去中心特征余弦不超过
0.2；正常/错配top-1一致率不超过50%。若失败，保持V7停止，不用原始余弦的事后解释放行。

### B1/B2：双seed五轮

仅在B0c和D34通过后启动。两个seed均要求validation AUC至少比各自CLS高0.2点，primitive
macro下降不超过0.5点，局部属性macro不发生长尾塌缩。任一失败，不读test、不扫描层位、
学习率或gate。

## 5. 后续解冻条件

只有当两个seed的ICAQ局部macro和错配审计都证明patch属性证据真实有效，但AUC融合仍未过门槛，
才考虑解冻最后两层视觉Adapter，并用冻结CLS蒸馏约束。若局部表征本身无效，不扩大模型容量。
