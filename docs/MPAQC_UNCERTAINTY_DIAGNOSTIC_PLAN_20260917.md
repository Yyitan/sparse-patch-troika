# MPAQC：CLS 不确定性与局部互补性诊断

日期：2026-09-17。使用P1/P2固定最佳checkpoint；validation-only；不训练、不调参、不读取test。

## 背景

D25/D26证明局部scorer对约3.4%的CLS条件对象错误有互补正确答案，但对更多CLS正确样本
有害。是否能用样本级gate取决于这些互补样本是否集中在CLS自身不确定的情况。

## 固定诊断

对每张验证图，在真实属性对应候选对象内计算CLS top-1与top-2分数间隔（该间隔不使用标签，
是潜在gate可见的置信度）。按全验证集该间隔升序严格等量分为5个20%分位。每个分位报告：

- CLS与局部条件对象Top-1；
- CLS错且局部对、CLS对且局部错、oracle上界；
- CLS top-1分数间隔范围与均值。

## 决策

- 只有当最低置信20%中“CLS错且局部对”明显高于整体3.4%，且局部净收益为正，才允许设计
  只依赖冻结CLS置信度的样本级gate；
- 若低置信分位也不能分离互补样本，关闭局部对象residual路线；
- 不使用诊断结果挑选阈值或评估test。
