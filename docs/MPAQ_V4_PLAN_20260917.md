# MPAQ V4：属性定位、组合文本评分

日期：2026-09-17

## 核心问题

MSAQ V3 的局部 residual 对一个属性的所有对象候选都相同，因此不能在
`Leather Bag` 与 `Leather Boot` 之间提供不同证据。对象 mask 又已经被多组对照否定，
因此对象应只在**评分端**参与，不应回到 patch 定位端。

## 结构

1. 保留 MSAQ 的属性文本 sparsemax 注意力：第12层语义 key + 第6层细节 value；
2. 每个属性得到一个局部视觉向量 `v_a`；
3. 对每个候选 pair `(a,o)`，使用其组合文本向量 `t_(a,o)` 计算
   `s_local(a,o)=cos(v_a, t_(a,o))`；
4. 通过零初始化 pair gate 加入原 Troika composition logit；
5. 不向 primitive attribute 分支加 residual，避免 D21/D22 已证明的不稳定路径；
6. 组合文本作为评分目标而非空间 Query，因此不产生对象 mask 或对象区域假设。

## 训练

冻结 Troika，只训练 MPAQ与 pair gate。

- 标准 Troika pair CE 保证残差服务 CZSL；
- 对 `s_local(a,o)` 加直接 pair CE，使每个对象候选都获得梯度；
- 保留局部 attribute 标准 CE 与 Balanced Softmax CE，维持 MSAQ 已验证的长尾结构；
- 固定五轮、两个 seed、validation-only。

## 新增工程检查

- 零 gate 精确复现 CLS；
- 对同一属性的不同对象候选，`s_local` 不允许恒等；
- pair scorer、属性 Query、多层 key/value 均应有非零梯度；
- sparsemax 保持非负、和为1、非零稀疏率。

## 门槛

- 两 seed validation AUC 都至少高于各自 CLS 0.2 点；
- 两 seed primitive macro 下降均不得超过0.5点；
- 两 seed local pair scorer 对同属性不同对象的分数方差必须非零；
- 任一失败，不读 test、不继续扫描。
