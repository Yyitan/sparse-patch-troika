# MSAQ V3：无对象 Mask 的多层稀疏属性 Query

日期：2026-09-17

## 已知证据

1. 中层 patch 对组合 AUC 有小幅互补，但原始 patch-text mean/max 很弱；
2. OCAQ/TGAQ 学习后的局部 Query 能改善部分组合排序；
3. 正确对象 mask 不优于错误对象或跨图 mask，不能继续解释为对象定位；
4. soft attention 无区域约束时过于弥散，属性-only分支又会向高频类塌缩；
5. 后验类别先验校准不能修复该塌缩。

## 结构

建立独立 `msaq_troika/`，原 Troika、OCAQ、TGAQ 目录不修改。

- 每个属性文本只产生一个 Query，不再为每个候选对象复制；
- 第12层 patch 经过可学习投影后作为语义 key；
- 第6层 patch 作为细节 value，并同时参与 key；
- 两层 key/value 使用可学习标量融合；
- patch 权重使用 sparsemax，不手工指定 top-k；
- 输出只由视觉 value 形成，不加入文本 Query residual；
- Troika 的 composition/attribute/object CLS 三分支完整保留；
- MSAQ 通过零初始化 pair gate 和 attribute gate 作为残差接入。

## 第一阶段训练

冻结 Troika，只训练 MSAQ 和两个 gate。固定五轮、两个种子，validation-only。

损失：

1. 原 Troika 训练 pair CE 和 attribute CE，推动残差 gate 面向 CZSL 目标；
2. MSAQ 局部属性标准 CE；
3. MSAQ Balanced Softmax CE，使用训练集类别计数，不再使用推理期先验修正；
4. 稀疏注意力本身由 sparsemax产生，不增加手工熵系数。

## 工程与性能门槛

- gate 为0时必须精确复现基线；
- 只有 `msaq.*` 和两个 gate 获得梯度；
- sparsemax 权重非负、和为1，并产生非零稀疏率；
- 双种子 validation AUC 都至少提高0.2个百分点；
- 双种子 primitive 属性macro均不得下降超过0.5个百分点；
- 未同时通过时不读取test、不解冻Troika、不扫描层位和稀疏参数。

## M0/M0c 工程结果

M0真实batch smoke通过：零gate与Troika基线最大误差为0，注意力归一化最大误差
2.38e-7，只有MSAQ和两个gate共5,906,693参数获得梯度，峰值显存1.95GB。

M0c在seed0/P0上固定训练一轮，作为工程与机制检查，不用于最终涨点结论。训练后
sparsemax注意力稀疏率从0.12%升至30.42%，有效patch数从218.29降至111.98，表明
没有退化成近乎全局平均。局部属性micro/macro达到30.62%/25.69%，MSAQ组合AUC为
50.7204，较CLS+0.1337点；primitive macro仅-0.1527点。AUC尚未到最终+0.2点门槛，
但稀疏性、局部判别和macro稳定性均通过工程检查，因此允许启动一次固定五轮双种子
validation-only验证。
