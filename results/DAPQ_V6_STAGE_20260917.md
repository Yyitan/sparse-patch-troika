# DAPQ V6 密集属性原型监督阶段结果

日期：2026-09-17。全部实验仅使用UT-Zappos validation，未读取test。

## 1. 验证目的

DAPQ保留MSAQ的layer12语义定位、layer6细节取值和sparsemax，并尝试让真实属性Query的
视觉特征在全部属性文本原型中分类，以补足原MSAQ只监督对角分数的问题。

## 2. D31/D32：旧MSAQ固定权重表征审计

| 指标 | seed0 / M1 | seed1 / M2 |
|---|---:|---:|
| true-query dense micro | 35.2831% | 32.4207% |
| true-query dense macro | 31.7291% | 30.1252% |
| 预测类别覆盖 | 13/16 | 13/16 |
| 最大预测类占比 | 57.4984% | 58.8986% |

旧MSAQ的patch特征具有一定跨原型判别力，但类别偏置明显，支持做一次监督机制筛查。

## 3. A0/A0c：工程检查与seed0一轮

A0中zero gate相对CLS最大误差为0，attention归一误差为2.38e-7，梯度只进入DAPQ参数，
峰值显存约1.82GiB。A0c一轮后：

| 指标 | 训练前 | 一轮后 | 变化 |
|---|---:|---:|---:|
| validation AUC | 50.5867 | 50.7423 | +0.1556点 |
| true-query dense macro | 7.1429% | 95.2225% | +88.0797点 |
| true-query dense micro | 0.9956% | 96.6397% | +95.6441点 |
| dense类别覆盖 | 1/16 | 15/16 | +14类 |
| primitive macro | 27.2797% | 27.2797% | 0 |
| attention稀疏率 | 0.1199% | 7.2886% | +7.1687点 |

异常高的dense准确率触发了预注册的标签捷径审计，没有直接进入双seed五轮。

## 4. D33：错配图像捷径审计

保持真实标签和第y个Query编号不变，把输入换成验证集中固定偏移的另一张图；88.4256%的
错配图像属性与原标签不同。

| 指标 | 正常图像 | 错配图像 |
|---|---:|---:|
| true-query dense macro | 95.2225% | 79.0031% |
| true-query dense micro | 96.6397% | 91.7548% |
| 类别覆盖 | 15/16 | 16/16 |

错配后macro仍保留正常值的82.97%，正常与错配图像的选中Query特征余弦相似度为0.9572。
这证明高准确率主要来自“第y个文本条件Query携带属性y身份”，而非读取对应图像patch。

## 5. 决策

DAPQ V6监督无效，取消A1/A2，不读取test，不扫描dense损失权重。下一版ICAQ移除属性标签
条件Query：使用冻结CLS属性特征生成唯一图像Query，再从layer12/layer6 patch提取属性特征，
对全部属性文本分类。这样CLS负责全局引导，patch负责细节，且Query不能提前知道真实属性。
