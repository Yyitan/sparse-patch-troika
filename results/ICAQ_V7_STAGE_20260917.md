# ICAQ V7 图像条件属性Query阶段结果

日期：2026-09-17。全部实验为UT-Zappos validation-only，未读取test。

## 1. 结构与目的

ICAQ用冻结Troika的attribute CLS生成每张图唯一Query，在layer12 patch上定位、从layer6
读取细节，再对全部属性文本原型分类。真实属性标签和属性文本Query均不参与Query生成，
用于消除DAPQ中“第y个Query携带y身份”的捷径。

## 2. B0/B0c工程与一轮筛查

B0 zero gate相对Troika误差为0，attention归一误差1.19e-7，冻结隔离通过，峰值显存约
1.82GiB。B0c seed0一轮结果：

| 指标 | 训练前 | 一轮后 | 变化 |
|---|---:|---:|---:|
| AUC | 50.5867 | 50.6865 | +0.0998点 |
| 局部属性macro | 7.1429% | 31.1815% | +24.0387点 |
| 局部属性micro | 0.9956% | 31.5806% | +30.5850点 |
| 类别覆盖 | 2/16 | 12/16 | +10类 |
| primitive macro | 27.2797% | 27.2797% | 0 |
| attention稀疏率 | 0.1157% | 4.4481% | +4.3324点 |

## 3. D34/D35/D36图像依赖审计

固定偏移替换88.4256%的不同属性图像，保留原标签。D34原始特征余弦较高，追加预注册D35
去中心审计；正式B2结束后对seed1做同协议D36。

| 指标 | seed0 / D35 | seed1 / D36 |
|---|---:|---:|
| 正常局部macro | 31.1815% | 32.2141% |
| 错配局部macro | 6.7247% | 7.2315% |
| macro保留率 | 21.5664% | 22.4482% |
| 原始特征余弦 | 0.9619 | 0.9506 |
| 去中心特征余弦 | -0.0449 | -0.0219 |
| 正常/错配top-1一致率 | 33.7274% | 29.4337% |

两个seed均证明局部属性预测依赖当前图像；高原始余弦来自公共特征方向，而非标签捷径。

## 4. B1/B2固定五轮

| 指标 | B1 / seed0 | B2 / seed1 |
|---|---:|---:|
| 最佳轮 | 2 | 1 |
| 基线AUC | 50.5867 | 51.4583 |
| 最佳AUC | 50.7557 | 51.3339 |
| AUC变化 | +0.1690点 | -0.1244点 |
| 局部属性micro | 31.2694% | 30.6161% |
| 局部属性macro | 27.9634% | 32.2141% |
| 类别覆盖 | 14/16 | 14/16 |
| primitive macro变化 | 0 | 0 |

局部属性分支在两个seed均学到真实图像证据，但直接以单一composition gate融合仍不稳定；
两个seed均未达到AUC至少+0.2点门槛，V7正式失败，不读取test，不扫描gate或patch层位。

## 5. 决策

满足进入视觉Adapter阶段的前提：局部表征在双seed有效且图像依赖审计通过，但冻结视觉端
融合失败。下一版只解冻ViT最后两个block的四个既有Adapter，并用冻结Troika教师在线蒸馏
未加局部residual前的composition/attribute/object CLS logits，防止破坏原模型能力。
