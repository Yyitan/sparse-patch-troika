# MPAQC V5 阶段记录

日期：2026-09-17。所有指标为 validation-only；未读取 test。

## 1. MPAQ V4 反例与定位

V4 直接以属性局部视觉向量匹配所有 `(属性, 对象)` 组合文本，并使用全局 local pair CE。
seed0 一轮 N0c 的 CLS AUC 为50.5867，V4为50.5823（-0.0044点），primitive macro无变化，
gate仅-0.00201。它未满足继续训练的趋势条件。

但固定 N0c 权重的 D23 显示局部 raw pair scorer 在真实属性已知时有68.4194%的对象Top-1，
正确对象对最强同属性错误对象间隔+0.3992；跨属性全局AUC却只有21.7746%。因此问题是
跨属性标定，不是局部对象区分完全失败。

## 2. MPAQC V5 方案

V5 将每个属性组内的 raw pair score 减去该组平均值，得到零均值残差，仅影响同属性对象
选择；训练局部 pair CE时也只在真实属性的对象候选内分类。CLS composition、attribute、
object 三个原分支均保留。

真实 batch 冒烟：零 gate 与 CLS 最大误差0，注意力和误差2.38e-7，raw pair score标准差
0.90599，中心化 residual标准差0.65740，条件 pair CE有限，峰值显存约1.95GB。

## 4. D24：条件对象机制复核

固定P1c权重，局部raw scorer单独跨属性AUC为17.0976%、全pair Top-1为13.0678%，不承担
全局CZSL排序；但真实属性条件下对象Top-1为**66.7704%**，平均每个属性候选10.1721个，
正确对象相对同属性最强错误对象间隔**+0.4850**。这支持“局部 patch 分支提供属性内对象
校正，CLS负责全局属性和组合标定”的分工。

## 5. 当前决策

按预注册固定配置，启动P1（seed0）与P2（seed1）各五轮的并行validation验证。只有两个
seed均至少提升CLS AUC 0.2点且primitive macro下降不超过0.5点，才允许讨论 test；否则停止
本版，不扫描额外超参数。

| 有效patch数 | 90.06 | 95.54 |

P1通过AUC与macro门槛，P2仅通过macro。因P2 AUC增益远小于预注册的+0.2点，MPAQC V5
整体失败，严格不读取test。值得保留的正面机制是：中心化后不会影响primitive macro，局部
稀疏属性表征稳定形成，且属性条件对象区分存在。失败点是局部对象残差与CLS组合排序的
互补性在seed1不稳定，甚至学习出负gate。

下一步只允许固定P1/P2 checkpoint做“CLS已知属性条件下的对象排序互补性”诊断：比较CLS、
局部scorer与完整融合在真实属性候选内的对象Top-1、margin和互补样本比例。该诊断不调参、
不训练、不读取test，用于判断是CLS本身没有剩余对象误差可修，还是局部正确样本与CLS错误
样本没有重叠。

## 7. D25/D26：条件对象排序互补性

| 指标 | D25 / seed0 | D26 / seed1 |
|---|---:|---:|
| CLS条件对象Top-1 | 86.2788% | 83.5719% |
| 局部raw scorer条件对象Top-1 | 74.7978% | 67.2060% |
| 完整MPAQC条件对象Top-1 | 86.3099% | 83.5719% |
| CLS错且局部对 | 3.3603% | 3.3914% |
| CLS对且局部错 | 14.8413% | 19.7573% |
| 二者任一正确的oracle上界 | 89.6391% | 86.9633% |
| 融合相对CLS实际纠正 | 0.1556% | 0.0311% |
| 融合相对CLS实际破坏 | 0.1245% | 0.0311% |

局部scorer确实对两个seed都有约3.4%的互补正确样本，oracle条件对象上界也有约3.4点
空间；但其错误量远大于互补量。学习出的全局gate在seed0谨慎地带来微小净修正，在seed1
接近关闭，符合正式AUC的不稳定性。结论不是继续增大residual，而是先验证互补样本是否
集中于可由CLS自身置信度识别的困难样本。下一步D27/D28只按CLS在真实属性候选内的top-1
间隔做固定五分位分层，不训练、不扫描阈值、不读取test。

## 8. D27/D28：CLS置信度五分位，关闭不确定性gate

最低置信的20%是唯一可能安全启用局部残差的区域，但两个seed结果均为负：

| 最低置信20% | seed0 / D27 | seed1 / D28 |
|---|---:|---:|
| CLS条件对象Top-1 | 57.6324% | 54.5171% |
| 局部条件对象Top-1 | 46.8847% | 39.2523% |
| CLS错且局部对 | 12.9283% | 12.9283% |
| CLS对且局部错 | 23.6760% | 28.1931% |
| oracle任一正确 | 70.5607% | 67.4455% |

其余四个置信分位中，局部相对CLS更弱，互补正确迅速降至3.4%、0.6%、接近0，且仍会破坏
5%-25%的CLS正确样本。低置信分位虽存在oracle空间，但局部净错误更多；固定置信度无法
辨别“CLS错且局部对”与“CLS对且局部错”。因此关闭样本级不确定性gate、全局gate及当前
属性条件对象residual路线，不训练该分支的任何后续变体，也不读取test。

下一步重新审视“对象先定位”的前提：此前被否定的是由当前CLIP文本attention产生的对象区域，
而非真实前景/对象box。只允许先做数据级前景定位可行性与对照诊断；若没有可信定位来源，
不再重复中心环或文本对象mask实验。
