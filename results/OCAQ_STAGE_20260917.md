## Q0：工程与梯度检查

第一次真实 checkpoint smoke 已完成：

- 零 gate 输出与 P0 基线最大绝对误差为 0。
- OCAQ 可训练参数 11,226,629 个，梯度非零且有限；冻结 Troika 参数无梯度。
- batch=2 峰值显存 1,899,575,808 bytes，约 1.90GB。
- 初始有效 Query 数约 4，但属性注意力两两重合度为 0.999998、归一化熵约 0.9992。

工程正确性通过，但初始注意力几乎相同。该现象若不处理，4 个 Query 很可能只复制同一种局部证据。因此在正式 Q1/Q2 前做一次透明的结构修正：四个 Query 分别采用可学习的核心、混合、邻域、近全局初始空间角色，然后重跑 smoke，并用 seed0 一轮短训练确认重合度有下降趋势。该修正发生在正式双种子训练和任何 test 读取之前。

结构修正后的 smoke 继续满足零 gate 误差为 0、梯度隔离正确，初始注意力重合度从 0.999998 降到 0.993890。随后运行 Q0c seed0 一轮完整工程训练：

- validation 注意力重合度降到 0.049364，说明四个 Query 已形成明显不同的 patch 关注区域。
- 有效 Query 数 3.9993，没有路由塌缩；归一化注意力熵 0.6944。
- 局部属性准确率 32.2962%，对象 Query 准确率 72.3398%。
- 真实对象条件优于错误对象的比例为 64.5302%，平均目标属性 margin 为 0.06889。
- AUC 50.5472，对 P0 基线 50.5867 为 -0.0395 个百分点；属性准确率 38.6434%，为 +0.0622 个百分点。
- 峰值显存 3,176,940,032 bytes；只保存 OCAQ 权重，checkpoint 44,925,618 bytes。

结论：Q0c 的用途是验证可训练性和分工，不用于宣称涨点。分工门槛通过，允许按固定结构启动 Q1/Q2 五轮双种子正式 validation 实验。

### 机制结论

1. 重复性最好的正信号来自组合残差：两个种子的 AUC 都提高，平均提高 0.4019 个百分点，但 seed1 没有达到单种子 +0.3 的正式门槛。
2. 属性残差对属性准确率的方向在两个种子上一致为正，但只有 +0.0933/+0.0622 个百分点，远小于预注册的 +1.0；它在 seed1 还使 AUC 下降。
3. 完整 OCAQ 的平均 AUC 提高 0.4623 个百分点，但最终属性准确率在两个种子都下降。说明当前局部分数更像组合排序修正项，还不是更可靠的独立属性识别器。
4. Query 的分工与可训练性已经得到肯定，失败点主要是属性判别能力和局部/CLS 分数校准，而不是 Query 数量塌缩。

## 阶段结论

本阶段完成 D11/D12、Q0/Q0c、Q1/Q2、D13/D14。所有正式结果只使用 validation，未读取 test。

OCAQ 比固定 patch mask 更有研究价值：它能在监督下形成四个明显不同的注意力区域，并在两个种子上产生方向一致的组合 AUC 增益。但它没有通过预注册门槛，尤其没有解决属性准确率问题。因此当前版本不进入 Q3/Q4，不解冻 Troika，不运行测试集，也不宣称为最终有效方法。

下一版若继续，应保留“CLS 主干 + 监督 Query”的总体方向，但优先重做属性学习与校准，而不是继续增加 Query 数或扫描 patch 超参数：先把 Query 训练成强于 CLS 属性分支的属性专家，再讨论组合残差。
