# RCR 前置机会审计结果：D37 / D38

日期：2026-09-18。实验为 UT-Zappos validation-only，零训练，未读取 test 图像。

## 1. 实验目的

本阶段检查固定 ICAQ 局部属性证据是否真正落在 Troika 的关键组合错误上。审计时将
`msaq_pair_gate` 强制置零，Troika 组合分数不含 ICAQ residual；ICAQ 只作为独立局部
属性专家参与错误交集和 oracle 上界统计。

预注册主门槛为两个 seed 同时满足：

- “ICAQ 属性 + Troika 独立对象分支”oracle 相对原组合 Top-1 至少提高 2 个百分点；
- `Troika组合错 ∩ 对象对 ∩ ICAQ属性对` 至少占全部验证样本 2%。

## 2. Troika 错误结构

| 指标 | D37 / seed0 | D38 / seed1 |
|---|---:|---:|
| 原始组合 Top-1 | 30.4605% | 34.4119% |
| 组合错误样本数 | 2235 | 2108 |
| 属性错、对象对 / 全部样本 | 55.5383% | 49.3777% |
| 属性错、对象对 / 组合错误 | 79.8658% | 75.2846% |
| 属性对、对象错 / 组合错误 | 10.6935% | 12.4288% |
| 属性和对象都错 / 组合错误 | 9.4407% | 12.2865% |

两个 seed 的结论一致：Troika 组合错误中约四分之三到五分之四属于“对象已经正确，属性
错误”。因此属性仍是当前 CZSL 的主要瓶颈，继续研究属性细节是合理的。

## 3. 候选与局部属性覆盖

| 指标 | D37 / seed0 | D38 / seed1 |
|---|---:|---:|
| 错误样本真实组合进入 Top-2 | 37.1812% | 33.7287% |
| 错误样本真实组合进入 Top-5 | 80.8054% | 73.5294% |
| 错误样本真实组合进入 Top-10 | 94.9441% | 91.7457% |
| ICAQ 属性 Top-1 | 31.2694% | 30.6161% |
| ICAQ 属性 Top-2 | 51.5868% | 47.9465% |

真实组合通常已经位于 Troika 的前几个候选中，说明候选召回不是主要问题。ICAQ 的真实
属性 Top-5 覆盖也较高，但 Top-1 只有约 31%，表明其包含软属性信息，却不足以作为稳定
的最终属性决策器。

30.4605%/34.4119%。

## 5. 结论

D37 通过，但 D38 未通过预注册双 seed 门槛，因此停止基于当前固定 ICAQ 专家的 RCR
训练，不读取 test，不扫描 gate、融合权重或候选数。

这个结果不否定 patch 属性信息，也不否定属性方向。相反，错误结构证明属性是主瓶颈，
Top-K 结果证明局部特征中存在软属性线索；失败点在于当前 ICAQ 的 Top-1 决策与 Troika
关键错误重叠太少，无法稳定提供关系重排所需的监督信号。直接把它接到组合分数上，很可能
继续出现 seed0 小幅上涨、seed1 无效或下降的模式。

## 6. 后续允许方向

若继续视觉端，不能复用当前 ICAQ Top-1 作为固定专家，也不能回到 patch 数量、中心邻域、
全局加性 gate 或扩大 Adapter 解冻范围。下一版应重新训练**候选对称、组合感知的属性
Query**：对所有候选属性-对象统一打分，不使用真实标签选择 Query；训练目标直接比较
同对象错属性和同属性错对象，并保留 Troika 高置信正确样本。

在启动该新架构前，需要单独预注册结构、负样本和一轮工程门槛，不能把本次失败解释成
继续训练原 RCR 的依据。
