# 2026-09-16 第四轮：layer6 residual 端到端 seed0 确认

## P8 设置

P8 使用 `code_v5/`，把 P7 在验证集唯一选中的方案固定后从 CLIP 初始化进行
15 轮端到端训练：ViT 第6层 patch、top-k2 log-mean-exp、只修改 composition
分支、与最终 CLS composition 分数按 alpha=0.25 做 residual 融合。属性/物体
分支保留 Troika 原 CLS 解耦表示。数据、seed0、优化器、batch64、学习率和验证
checkpoint 选择规则均与 P0 相同。

## 解释

按照预先规定的验证集优先判断，P8 没有超过 P0，因此 seed0 端到端确认是阴性
结果。虽然 P8 测试 AUC 和 HM 分别高 0.8283、1.0777 个百分点，但该配置源自
P0 checkpoint 的验证扫描，端到端 P8 自身的验证 AUC 明确较低，不能根据测试集
反转结论或宣布性能提升。

P8 的训练 loss 持续下降，而验证 AUC 从第3轮49.5535下降到第15轮34.1013，
继续呈现明显早期过拟合。固定 checkpoint 上的 layer6 局部补充信号没有稳定转化
为端到端验证增益。

当前不启动 seed2。P9/P10 seed1 配对仍在训练，必须等待两者完成后做同 seed
比较。如果 P10 同样未超过 P9，停止 layer/k/alpha/kernel 扫描，下一步只考虑
对象条件化 soft aggregation 或原图/翻转响应一致性约束的最小诊断。
